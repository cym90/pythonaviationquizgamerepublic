
# ✈️ 항공·공항 상식 퀴즈 (Aviation & Airport Quiz)

> **"당신의 항공 지식은 몇 점일까요?"**
> 웹 브라우저에서 간편하게 즐길 수 있는 인터랙티브 **항공·공항 상식 퀴즈 웹 애플리케이션**입니다.

---

## 📋 1. 프로젝트 개요

* **프로젝트명:** 항공·공항 상식 퀴즈 (Aviation & Airport Quiz)
* **개발 목적:** 일상에서 접하기 쉬운 항공 및 공항 관련 상식을 퀴즈 형태로 재미있게 학습하고, 자신의 지식을 테스트할 수 있도록 제작되었습니다.
* **주요 특징:**
* 별도의 백엔드나 설치 없이 **HTML/CSS/JS 단일 파일**로 동작
* 반응형 디자인을 적용하여 PC와 모바일 환경 모두 지원
* 로컬 스토리지(`localStorage`)를 이용한 **최고 점수 저장** 기능 제공



---

## 🎯 2. 퀴즈 주제 및 선정 이유

* **주제:** 항공 상식 및 공항 이용 절차/시설
* **선정 이유:**
* 비행기 탑승이나 공항 이용은 많은 사람들이 경험하지만, 활주로(Runway), 주기장(Apron), 관제탑(ATCT), 계기착륙시설(ILS) 등의 전문 용어나 공항 시스템에 대해서는 생소한 경우가 많습니다.
* 흥미로운 문항과 상세한 해설을 통해 누구나 쉽고 직관적으로 항공 지식을 넓힐 수 있도록 기획했습니다.



---

## 🚀 3. 실행 방법 (How to Run)

이 프로젝트는 별도의 서버 구축이나 패키지 설치 필요 없이 웹 브라우저만 있으면 실행할 수 있습니다.

1. 이 저장소를 클론(`git clone`)하거나 ZIP 파일로 다운로드합니다.
2. 프로젝트 폴더 내에 있는 **`aviation_quiz.html`** 파일을 더 마우스로 더블 클릭합니다.
3. 사용 중인 웹 브라우저(Chrome, Edge, Safari 등)에서 게임을 즐기실 수 있습니다.

*(또는 GitHub Pages 기능을 활성화하여 웹 상에서 바로 플레이 링크를 제공할 수도 있습니다.)*

---

## ✨ 4. 주요 기능 목록

* **랜덤 문제 출제:** 총 보유한 문제 중 매 게임마다 10문제를 무작위로 추출하여 제공합니다.
* **실시간 채점 및 피드백:** 4지선다형 선택지 클릭 즉시 정·오답 여부를 시각적으로 표시합니다.
* **상세 해설 제공:** 정답 여부와 함께 이해를 돕는 친절한 해설 카드가 하단에 노출됩니다.
* **진행 상황 바(Progress Bar):** 현재 몇 번째 문제를 풀고 있는지 시각적인 바 형태로 안내합니다.
* **결과 등급 및 최고 기록:**
* 정답 개수 및 정답률 계산
* 점수에 따른 칭호 부여 (항공 지식 마스터, 항공 전문가 등)
* 브라우저 저장소를 통한 **나의 최고 점수 갱신** 기능

## 💾 6. 데이터 및 저장소 설명 (`localStorage`)

* **역할:** 사용자가 게임을 진행하며 달성한 역대 최고 점수(`aviationBest`)를 클라이언트의 브라우저 로컬 스토리지에 영구 저장합니다.
* **데이터 키(Key) 및 형태:**
* Key: `aviationBest`
* Value: 점수 데이터 (예: `80`, `100` 등 숫자형태 문자열)


* **특징:** 서버를 사용하지 않고 브라우저 자체 저장소를 활용하므로, 브라우저를 닫았다가 다시 열어도 이전 최고 기록이 안전하게 유지됩니다.

## 📝 8. 문제 추가 및 수정 방법

`aviation_quiz.html` 파일 내부의 `<script>` 태그 영역에 있는 `questions` 배열을 수정하여 누구나 쉽게 새로운 문제를 추가하거나 수정할 수 있습니다.

```javascript
const questions = [
  {
    category: "카테고리 이름",
    q: "출제할 문제 내용",
    options: ["선택지1", "선택지2", "선택지3", "선택지4"],
    answer: 0, // 정답 인덱스 (0 = 첫 번째 선택지, 1 = 두 번째 선택지...)
    explain: "문제에 대한 상세 해설 내용"
  }
  // ... 추가 가능
];

```
